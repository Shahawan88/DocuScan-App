# DocuScan PDF

A lightweight, 100% offline Android document scanner and bulk gallery-to-PDF converter powered by Google ML Kit.

## How to Build APK & AAB on GitHub (Free)
1. Unzip this folder on your computer or phone.
2. Create a new **Public** repository on GitHub.
3. Click **Add file -> Upload files** and drag all extracted files/folders (including the `.github` folder) into GitHub, then click **Commit changes**.
4. Open the **Actions** tab on GitHub, wait for the green checkmark (~2-3 minutes), and download **`DocuScan-App-Files`** under **Artifacts** to get your `.apk` and `.aab` files.
